# 🌍 Global Travel and Tourism Analytics Dashboard

## 📌 Project Overview

The **Global Travel and Tourism Analytics Dashboard** is a Power BI project designed to analyze travel and tourism data through interactive visualizations. It helps users explore tourism costs, destinations, traveler information, and weather conditions.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Download the `.pbix` file.
4. Open the file using Power BI Desktop.
5. Explore the dashboard pages and available interactive filters.
